# Fabric Platform Fundamentals

This section introduces Microsoft Fabric as a **unified, end-to-end SaaS data platform**.

It covers the purpose of Microsoft Fabric and provides an overview of its major workloads:

* Data Factory
* Real-Time Intelligence
* Databases
* Data Engineering
* Data Warehouse
* Data Science
* Industry Solutions
* Power BI

The focus is understanding what each workload does and how the workloads work together within the Microsoft Fabric platform.
